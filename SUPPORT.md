# Support policy

`fastapi-cache-stable` is a community-maintained, drop-in stable fork of
fastapi-cache2.

## Supported lines

- `0.3.x`: security and critical correctness fixes for 12 months after the first
  stable `0.3.0` release.
- `1.x` (planned): security and critical correctness fixes for 24 months after
  the first stable `1.0.0` release.
- Feature work is best effort.
- The support window is reviewed annually.

## Handover

- A co-maintainer will be added before the `1.0.0` release.
- If the maintainer cannot continue, the project will be handed to a
  co-maintainer or moved to maintenance mode with a public notice.
- The code is Apache-2.0 and can be forked.
