Namespace the internal `_spec_type` marker as `__fastapi_cache_spec_type__` so user payloads
with `_spec_type` are preserved. `JsonCoder` now bypasses non-JSON `Response` objects
(`StreamingResponse`, `FileResponse`, `RedirectResponse`, plain `Response`, templates) unless
the coder's `can_encode` supports them; `PickleCoder` can still round-trip them. Old cache
entries written with `_spec_type` are treated as user data; flush the namespace if you cache
`datetime`/`date`/`Decimal` values.
