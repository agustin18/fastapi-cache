`FastAPICache.init()` now raises `RuntimeError` when called a second time instead of
silently keeping the first configuration. Call `FastAPICache.reset()` before
re-initializing, or pass `force=True` to replace the current configuration explicitly.
Applications that call `init()` from a lifespan handler must pass `force=True` or reset
first, because the handler runs on every startup. The bundled examples do this.
