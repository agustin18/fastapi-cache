# Security policy

## Supported versions

- `0.3.x`: security fixes.
- `1.x`: security fixes (planned).

## Reporting a vulnerability

Use GitHub private vulnerability reporting:

https://github.com/agustin18/fastapi-cache/security/advisories/new

Do not open a public issue for security reports. We aim to acknowledge within
3 business days and provide a remediation plan within 10 business days.
